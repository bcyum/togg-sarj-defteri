# Togg Şarj Defteri

Togg T10F (89,5 kWh LFP) şarj kayıtlarını tutan, şarjlar arası tüketimi (kWh/100 km), TL/kWh fiyatını ve 100 km maliyetini hesaplayan küçük web uygulaması.

- Uygulama: https://bcyum.github.io/togg-sarj-defteri/
- Kayıtlar: `data.json` (uygulama GitHub API ile bu dosyayı günceller)

Telefonda Safari'de aç → Paylaş → **Ana Ekrana Ekle**.
